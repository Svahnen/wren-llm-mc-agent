# wrenmap: BlueMap overlay for Wren (Fabric server mod)

Shows Wren's trail, home, nearby mobs and a status panel on the BlueMap web map. It has no network listener of its own: it writes markers through the
BlueMap API from `wren.json`, which `run-writer.sh start` keeps up to date. Build: `./build.sh` (rootless podman + pinned Gradle image, unit tests run
inside the build), copy `build-out/wrenmap-*.jar` to `server/data/mods/`. Setup: see the main README, section 7.

- The 80 mob icons are original abstract vector drawings generated by `tools/gen-icons.mjs`; they contain no Mojang assets.
- Builds download Mojang's official mappings (Microsoft licence: development use only, no redistribution of the mappings); the built jar contains remapped
  intermediary names, not the mappings.
- BlueMap's `accept-download: true` makes BlueMap download Mojang's client jar to your machine: that is your acceptance of the Minecraft EULA terms for it.
